# Archivos de imágenes de assets (PNG con fondo transparente)
# Coloca aquí las imágenes antes de ejecutar generate_dataset.py:
#
#   assets/
#   ├── mariposa1.png  ... mariposa3.png   (mariposa — class 0)
#   ├── mariquita1.png ... mariquita3.png  (mariquita — class 1)
#   ├── cucaracha1.png ... cucaracha3.png  (cucaracha — class 2)
#   ├── cruz.png                           (marcador de esquina — class 3)
#   └── laser.png                          (punto láser — class 4)
#
# También puedes usar nombres simplificados:
#   mariposa.png, mariquita.png, cucaracha.png
# (configurables en .env mediante la variable img_clases)
#
# Todos los archivos PNG deben tener fondo transparente (modo RGBA).
